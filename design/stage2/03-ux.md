# Stage 2 — UX / UI (designer)

Scope: the 1946 skin, the handover into Stage 2, the "checks → operations" rename, the Legacy line, and
what in today's UI is hard-wired to Stage 1. Layout does not change. Panels keep their positions.

## 1. Era skin `body.era-1946`: machine room and punch cards
Mood: pale green-grey machine-room paint, manila punch-card cards, a deep **console teal** accent.
Teal, not IBM blue, because blue already means IN TOTAL; the goal-kind hues stay the same in every era
so "blue = in total, red = you have" survives the stage change. All ratios are checked with WCAG.
```css
body.era-1946 {                        /* light: text #000 on every surface (17.2:1 / 18.2:1) */
  --bg:#e4eae6; --surface:#f5efd9; --bar-bg:#c9d3cd;
  --text:#000000; --muted:#22302a; --border:#000000; --soft-border:#5c6b64;
  --accent:#0b5563; --accent-text:#ffffff;            /* 6.9:1 on bg, white on it 8.4:1 */
  --ok:#1d5c2a;
  --k-balance:#9b1c1c; --k-lifetime:#1f3f8f; --k-owned:#7f4500; --k-clicks:#5b2a86; --k-ready:#1d5c2a;
  --k-on:#ffffff; --hatch:rgb(255 255 255 / 0.35);
  --font-era:'IBM Plex Sans Condensed', 'Arial Narrow', sans-serif;
}
/* dark: "steel cabinet". Same block twice: @media (prefers-color-scheme: dark) with
   :root:not([data-theme="light"]) body.era-1946, and :root[data-theme="dark"] body.era-1946 */
  --bg:#0e1618; --surface:#16222a; --bar-bg:#26343b;
  --text:#e9f0ea; --muted:#c4d0c8; --border:#e9f0ea; --soft-border:#7d8f88;
  --accent:#5ccfc0; --accent-text:#0e1618;            /* 9.7:1 on bg, bg on it 9.7:1 */
  --ok:#8fd19e;
  --k-balance:#ff9180; --k-lifetime:#8fb4ff; --k-owned:#f2b45a; --k-clicks:#c9a2f0; --k-ready:#8fd19e;
  --k-on:#0e1618; --hatch:rgb(0 0 0 / 0.35);
```
- **Goal-kind colours.** Only one changes: light `owned` goes from `#8a4b00` to **`#7f4500`**, because the old value gives
  4.43:1 on the new bar and the new one gives 4.97:1. Every kind is ≥ 4.97:1 on `--bar-bg`, ≥ 6.2:1 on `--bg` and ≥ 6.6:1 on `--surface` in light mode.
  In dark mode every kind is ≥ 5.9:1 on the bar and ≥ 7.4:1 on the surface. `--k-on` gives ≥ 7.6:1 on every tag.
- **Fonts.** Add `IBM+Plex+Sans+Condensed:wght@700` to the existing Google Fonts link. It replaces Special Elite
  only where `--font-era` is used today (`h2`, `#era-date`, log `.when`). In this era, `h2` gets
  `font-weight:700; text-transform:uppercase; letter-spacing:0.08em` at the **same** 1.15rem size (bold, not bigger).
  Body text, numbers and buttons stay in Plex Sans/Mono.
- **Details** (each is a few lines of CSS, with no images):
  - Cards get a punch-card **cut corner**: a `::before` 0.75rem triangle in `--surface` at the top left, with a 2px
    `--border` diagonal (a gradient). Do not use `clip-path`, because it would clip the focus outline.
  - `#era` gets `border-bottom: 3px double var(--border)`, like a console panel edge.
  - Producer rows use a dotted divider (`1px dotted`) instead of a dashed one.
  - `.main-btn` keeps the square corners and gets a 4px hard shadow, like a console key. The pressed state stays as it is.
- **Structure.** Today the 1939 tokens sit on `:root`. Keep them there as the default, and let `body.era-1946` override them,
  so a missing token falls back to 1939 instead of breaking. `--k` is resolved on `body`, so the overrides apply.

## 1b. One palette per stage: a deliberate progression
Every stage gets its own calm background and accent, in both modes. The palette is a first-class part of each era.
**Rules for every stage** (they apply to all ten rows below):
- Backgrounds are **tinted neutrals**: saturation ≤ 15 %, light mode L ≥ 88 %, dark mode L ≤ 10 %. Never a saturated or harsh background.
- Light-mode text is `#000000` on every surface (≥ 16.8:1, so AAA). Dark-mode text is a tinted off-white (≥ 15:1, AAA).
- Accents are ≥ 4.5:1 on bg and surface (AA). The text on an accent button is ≥ 7:1 (AAA).
- No accent may be red, blue or green, because those hues mean SAVE UP, IN TOTAL and READY in every era.
- `prefers-color-scheme` is respected and the manual toggle still wins. Each era has a light block and a dark block (§1 pattern).

| # | Era feel | Light bg / accent | Dark bg / accent | Contrast (L acc / D acc) |
|---|---|---|---|---|
| 1 | Paper, typewriter (built) | `#f3eddf` / red ink `#9b1c1c`* | `#0f1520` / `#ff9180` | 7.0 / 8.4 |
| 2 | Machine room, punch cards | `#e4eae6` / teal `#0b5563` | `#0e1618` / `#5ccfc0` | 6.9 / 9.7 |
| 3 | Beige plastic, amber terminal | `#ece6d6` / amber `#8a4600` | `#121410` / phosphor amber `#e8b04a` | 5.7 / 9.5 |
| 4 | 90s desktop and web | `#e3e6ec` / magenta `#8a1f5c` | `#14161c` / `#f09ac4` | 6.9 / 8.7 |
| 5 | Dot-com gold | `#efe9df` / gold `#7a4f00` | `#17140f` / `#f0c060` | 5.9 / 10.9 |
| 6 | Server hall, olive LEDs | `#e6eae4` / olive `#4f5a12` | `#10140f` / `#c4d27a` | 6.2 / 11.4 |

The arc runs from warm (paper, beige, gold) to cool, then to grey, then towards black and white. Colour drains away as the machine takes over. Only the Stage 2 row is final now. The others are a sketch, and each one is re-checked when its stage is built.
The IN TOTAL blue (`#1f3f8f` / `#8fb4ff`) stays ≥ 7.8:1 on every light bg and ≥ 8.7:1 on every dark bg in the table.

**Cross-fade at the transition:** `body { transition: background-color .6s, color .6s }`, and the same on `.panel, .card, .buy-btn,
#goal, #click-wrap` for `background-color, border-color`. During the swap, text never drops below AA, because
light mode stays `#000` and the dark text colours of the two eras are almost the same.

## 2. The stage transition (about 2.6 s, in place, never blocks input)
No overlay and no title card. The engine switches to Stage 2 **at t = 0** when "Pass the ledger on" is clicked.
Everything below is cosmetic. Any key or click during the transition (including the main button, which works
from t = 0) adds `.skip` to `body`, which jumps every animation to its end state.
| t (ms) | What happens |
|---|---|
| 0–150 | The Pass button fades out. The new main button (Stage 2 `clickLabel`) fades in at the same spot and is clickable at once. |
| 0–600 | **Collapse.** The faded old producer rows in "Your team" fold up (`grid-template-rows 1fr → 0fr`, 450 ms). In the same spot the **Legacy row** opens, with its number already final (see §4). `#team-complete` is removed. The rate line **does not change**: same number, same position. That is the message: you keep the speed. |
| 400–1000 | **Palette cross-fade** (§1b). `body` class changes from `era-1939` to `era-1946`, and the background, panels and buttons blend over 600 ms. The goal-kind colours do not move. |
| 400–700 | **Date.** "June 1945" slides up and out, and "February 1946" slides in from below (300 ms, clipped to its box, like a counter wheel). |
| 600–1100 | **Role.** "Codebreaker" crossfades to "**Director of a computing lab**" and gets a 2px `--accent` underline that stays for 2 s, then fades. |
| 900–1300 | **Ledger.** A divider row is added: `── Stage 2 · The computing lab ──` (bold, centred, no date). Under it the `next` line arrives with the normal `.fresh` animation (ENIAC, Feb 1946). |
| 1300–2000 | **Goal bar.** It drains and refills from 0 to the new stage goal, with the existing 03b §d animation and the outline in `--k`. |
| 2000–2600 | The first Stage 2 producer row appears under the Legacy row (`appear`), followed by the Ideas panel once its reveal rules allow it. |

**Reset:** producers, bought upgrades, choices, revealed cards, finale index, phase back to `playing`, and the click
bonuses that came from upgrades. **Kept:** balance (`s.ops`), lifetime total, the ledger, date, theme, `clicks` and
the speed (now the Legacy line). **UI caches must reset too** (see §5): `prodEls`, `cardEls`, `lockedEl`, `bigEl`,
`goalKind`, `etaCache` and the `#producer-list` children.
**Reduced motion:** everything swaps instantly, and the Legacy row and header get a static 2px `--accent` outline for 1 s.
**Screen readers:** one polite announcement: "1946. You are now Director of a computing lab. Your speed carries over."

## 3. The unit rename (1948): "checks" → "operations"
Triggered by a Stage 2 beat with a new `rename: 'operations'` field. The unit becomes state (`s.unit`), not a constant.
1. **Counter only animates** (one visual cue per event): the word next to the big number gets a 2px line struck through it
   from left to right (250 ms, the way a clerk corrects a ledger). The struck word then fades out (150 ms), and
   "operations" fades in (200 ms) with a 2px `--accent` underline that stays 3 s. The **number never flickers**: it is
   a separate span and is not touched. The centred line shifts a little because the word is longer. This happens while the word is invisible, so it does not show.
2. **Everywhere else** (costs, producer text, Legacy row, total line, goal text, ETAs) the word swaps in the same frame without animation.
3. **Log line** (milestone style, bold), from data, with the live total filled in, e.g.
   "Engineers stop saying checks. The new word is operations. The count does not start again: 1.23 million so far."
4. **Total line:** "Checked in total: N" becomes "Operations in total: N". Both strings come from stage data.
5. **Screen readers:** a visually hidden `aria-live` node says "Checks are now called operations."
Reduced motion: instant swap, with no strike-through. The underline still shows for 3 s.

## 4. The Legacy line
**Place:** the first row of "Your team", above every Stage 2 producer. It is there from the first frame of Stage 2,
so the panel shows at once (today the panel waits for an unlocked producer). It never moves, has no button and cannot be bought.
```
 YOUR TEAM
 Bletchley Park, 1945                                  LEGACY
 26,400 checks per second, forever.
 ··························································
 Valve computers                                      2 owned
```
- The label comes from Stage 1 data (`legacy: 'Bletchley Park, 1945'`), and the unit word follows the rename.
- The "LEGACY" tag uses the same pill style as the goal tag, but in `--soft-border` / `--surface`, so it reads as permanent, not as a goal.
- The number uses `fmt` (3 significant figures), exactly like the rate line. It is fixed, and it never flashes.
- **Stage 3 onward:** there is still one row. The label lists the eras ("Bletchley Park 1945 · the lab 1971") and the number is the combined legacy.
**Rate line:** the headline number stays the total (legacy plus team), so "never slower" is visible. While legacy is
≥ 5 % of the total, a muted segment is added: `+31,200 per second  ·  26,400 legacy  ·  +40 per click`.
It disappears for good the first time a purchase pushes legacy under 5 %. It changes only on purchases, so it stays calm (03b rule).
The team line ("as fast as …") uses the total too.

## 5. What is hard-wired to Stage 1 today, and what it should become
Rule: **every player-facing sentence that names the era lives in `src/data/stageN.js`.** `ui.js` and `engine.js` only fill in templates.
| Where | Today | Becomes |
|---|---|---|
| index.html `<body class="era-1939">` | fixed | `render()` sets `body.className` from `st.era` (keep the state classes) |
| index.html `#team-complete` | "The team is complete. Every check now goes to the war." | `st.text.teamComplete`; S2 e.g. "The lab is complete. Every operation now goes to the Moon." |
| index.html `#next-stage` panel | "To be continued / Stage 2 … is not built yet" / "Start again from 1939" | shown only when `STAGES[n+1]` is missing. Text: "The next stage is not built yet." and "Start again from {STAGES[0].era}" |
| ui.js team line | "as fast as N people with pencils", `person` | `st.compare = { rate, one, many }`, e.g. S2 `{rate:5000, one:'one ENIAC', many:'{n} ENIACs'}`. Naming a machine is fine here because it is not a button |
| ui.js team line | `st.task.label.toLowerCase()` | keep. S2 needs its own `task` (e.g. "Computing one Moon trajectory") |
| ui.js `#total-text` | "Checked in total: …" | `st.text.total` with `{unit}`, renamed in §3 |
| ui.js producer text | `.replace('1 guesses','1 guess')` hack | `each` template with `{out} {unit}`, plus `unitOne` for 1 |
| ui.js `prodEls`, `cardEls`, `lockedEl`, `bigEl`, `goalKind`, `etaCache` | never cleared | clear them (and `#producer-list`) when `s.stage` changes, or the 1939 rows stay on screen |
| ui.js Your-team visibility | needs an unlocked producer | also show it when `s.legacyRate > 0` |
| engine.js `currentGoal()` | "Check N guesses in total to …" | `st.goal.phrase` template, e.g. "Run {n} {unit} in total to put a computer on the Moon" |
| engine.js `conditionProgress()` | "Check N guesses in total / by hand" | `st.text.lifetimeVerb` and `st.text.clickVerb`, filled with `{n} {unit}` |
| engine.js `passLedger()` | `phase = 'next'` | go to `stage + 1` when it exists, otherwise `next` |
| main.js away note | "your team checked N guesses" | `st.text.away` template, e.g. "your lab ran {n} {unit}" |
| index.html main button / data | "Check a guess" | already `st.clickLabel`; S2 needs a plain label, e.g. "Run a calculation" |
| index.html "Pass the ledger on" | fixed | keep it: it is the same ritual in every era (D6) |
| style.css `:root` tokens | the 1939 skin | keep as the default; per-era blocks override (§1) |
| favicon | red `#9b1c1c` | fine to keep. Optional: per-era colour later |
