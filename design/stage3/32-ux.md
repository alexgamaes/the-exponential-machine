# Stage 3 screen, restart: the garage as a shop floor (UX spec, Nov 14)

Screen for the shape in `30-restart-brief.md`: one button builds a computer into a warehouse, a price with Lower/Raise,
buyers, chips bought in batches at a moving price, ads, workbenches then factories, every computer sold keeps counting.
Numbers are **placeholders** (the game designer sets them). `review/05-ux-layout.md` still holds. Replaces `23-ux-series.md`.

**Principle (Paperclips):** one label, one number, the button that changes it, on one line. No sentences in panels.
A panel row is `Label ......... number  [button]` with the label left, number right-aligned in tabular digits in a
fixed-width cell, buttons after the number. Explanations go to the ledger, once, when the thing first happens.

## 2. Every number and control
| Where | Label | Number / control | Changes when |
|---|---|---|---|
| Core, left | `You have` | operations, counter | homes + earlier machines run; ideas spend it |
| Core, left | rate line | `+31.0 million per second` (no "per click" in Stage 3: the click makes a computer) | each sale, better chips |
| Core, under both | homes line | `*N computers in homes.* Each new one: +X per second.` | each sale (N); better chips (X) |
| Core, right | `Money` | `$` counter + `+$ per second` (from first sale) | sales; buying |
| Core | main button | `Build a computer · 1 chip`; out of chips: `[- No chips -]` same width | chips stock |
| Garage | `Warehouse` | count + tag | build adds, sale removes |
| Garage | `Price` | `$395` `[Lower] [Raise]` | the player; Sales team idea adds `[Auto: on]` in a reserved cell |
| Garage | `Buyers` | `1.4 a second` + `you build 2.0` | price (at once), ads, buyer ideas, twist |
| Garage | `Chips` | stock `[Buy N · $cost]` (+ `[Auto: on]` after Standing order) | each build −1; buying |
| Garage | `Chip price` | `$42 ▲` + tag `Cheap` / `Dear` / none | the market, in steps |
| Garage | `Ads` | `level 2` `[+0.4 buyers · $800]` | buying a level |
| Builders | `Workbenches`, `Factories` | owned count `[Buy · $cost]`, muted line `each builds 1 every 2 s` | buying; builder ideas |
| Ideas | cards | name + cost (operations swatch) / one bold effect line / `~40 s` | as today |

**The loop at a glance (price → buyers → warehouse).** Three adjacent rows, read top to bottom. The *Buyers* row puts
the two flows side by side (`Buyers 1.4 a second  you build 2.0`), and the *Warehouse* row carries the result as one
tag in a fixed cell at its right (width of the longest tag, so nothing shifts):

| Tag | When (built and sold rates, averaged over 5 s) | What the player reads |
|---|---|---|
| `▲ Piling up` (bold) | warehouse grows by > 5% of buyers | too dear or too few buyers: Lower, or Ads |
| `▼ Selling fast` | warehouse shrinks | fine for now; it will hit zero |
| `*Sold out*` (bold) | warehouse 0 and buyers > what you build | you leave money on the table: Raise, or build more |
| (empty) | otherwise (steady) | |

A new tag shows only after holding **2 s**. The tag is the only words in the loop: no verdict, no fix sentence (Paperclips
trusts a rising pile to say "lower the price"). The ledger says it once, the first time each tag shows.

**Chip price without flicker.** The engine moves the price in discrete steps (suggest every 4–5 s, never per frame).
- The number swaps in place in a fixed tabular cell sized for the widest price; no animation, no colour flash.
- The arrow (`▲`/`▼`) shows the last step and stays until the next one. No arrow while the price has not moved.
- One tag in a fixed cell: `Cheap` (bold) when the price is in the lowest quarter of the last 60 s, `Dear` in the
  highest quarter, otherwise empty. That is the whole timing game: buy on *Cheap*. No sparkline (the player dislikes
  abstract charts); the long fall over the stage is told by the number itself and by the ledger (`The $25 chip.`).
- Low stock: when chips last < 10 s at the current build speed, the `Chips` number turns bold. At 0 the Chips row
  becomes a solid accent band `Chips  0  *Out: nobody can build*  [Buy …]` (same height) and the main button reads
  `[- No chips -]`. The band style is the one the player liked for "switching over".

**"Computers in homes keep counting for you".** Three things, all concrete:
1. The homes line sits **directly under the operations rate**, so the eye goes counter → rate → why. It names the
   reward of one sale in the counter's own unit: `Each new one: +2,000 per second.` Before the first sale:
   `*No computers in homes yet.* Each one sold: +2,000 per second.` (This replaces the Cray-1 comparison line.)
2. Every sale visibly bumps both the homes count and the rate line in the same frame (they are counters; tabular
   digits so the width never jiggles). Unsold computers change neither: the warehouse number sits right below and
   does nothing, which is the lesson.
3. *Better chips* ideas raise `+X per second` on the homes line at once; the card says `New computers run 2× as fast.`
   Ledger at the first sale: `Your first computer goes home with a teacher in Ohio. Its work counts for you now.`

Rates update once a second at 2 significant digits; counters tick freely. Buttons have fixed min-widths for their
widest cost; disabled = dashed, never hidden. Lower/Raise change Buyers at once (the player acted).

## 3. Reveal order (append below, reserve inside)
Two rules make "nothing moves": (a) **inside a panel**, every row it will ever have is reserved from the panel's first
frame (invisible `░` slots); (b) **new panels are only appended at the bottom of a column**, below everything shown.

## 4. Text deleted, compared with the current Stage 3
Gone from the screen (the current panel has ~110 words; the new Garage + Builders panels have **≤ 45 words at minute
10**, almost all of them labels):
- the whole "Your computers on sale" panel: model tag, intro, sales chart, `Buyers … · you can make …` line, the
  2-line verdict and fix, both launch rows (heads, phase words, bars, buttons, 2–3 line notes), customer list.
- the Homes row in "Your team": `Model N runs ×r as fast as Model 1`, the series table (Homes / Programs / Boost),
  the programs line, `Together: …`. All of it collapses into the one homes line under the counter.
- the Cray-1 comparison sentence and the task ETA on the `#team` line (the homes line takes its slot).
- producer descriptions `Each builds 1 computer. Together: 4 per second. …` → `each builds 1 every 2 s` (the
  total is already on the Buyers row as `you build`).
- the Legacy row and `+N per click` on the rate line (the rate already includes the legacy; the click makes computers).
- Card text: one bold effect line only, ≤ 6 words (`New computers run 2× as fast.`, `More buyers: +50%.`,
  `Buys chips for you when cheap.`). Story goes in the ledger line the purchase writes.

Wording rules for the game designer's data: labels ≤ 2 words, nouns (`Warehouse`, `Chips`, `Ads`); buttons are verbs or
gains (`Buy 50 · $2,100`, `+0.4 buyers · $800`); no "×" ratios on the panels except card effects; locked things say
why in one line: `Locked: build 500 computers (310 of 500).`

## 5. Themes, era skin, contrast
- **Light (beige case)** and **dark (amber terminal)**: existing `body.era-1971` tokens, no new colours. Panel rows use
  `--text`; the bold tags (`Piling up`, `Sold out`, `Cheap`) use `--text` at weight 700, never colour alone. Money
  costs carry the `--k-money` swatch, idea costs the operations swatch (`--k-balance`), as today.
- The two alarm states (Out of chips band, `[- No chips -]`) use `--accent` fill / `--accent-text` (brown on beige,
  amber on near-black), the pair already used for buttons on hover; check 4.5:1 when built.
- Titles in `--font-era` 700 (as `h2` today); labels `--font-ui` 600; numbers `--font-num` 700, all at body size.
  **Bold, never bigger**: only the two core counters are larger, as in every stage.
- Case stripe stays. Only motion: the existing 0.25 s `appear` when a slot fills (off with reduced motion).
- **High contrast** (`prefers-contrast: more`): `--soft-border` → `--border`, `--muted` → `--text`, disabled buttons
  keep the dashed border (shape, not colour), arrows ▲▼ stay as glyphs (never colour only), the muted
  "each builds…" lines become normal weight `--text`.
- The faded hand button uses `--soft-border` border and `--muted` text, never opacity (too faint on amber-on-black).

## 6. Open points for the game designer (the screen adapts)
Price step (fixed or %), chip batch sizes (the button cell is sized for the largest), chips vs "parts" (label only),
the twist (an appended 2–3 row panel, or the Price row's reserved right cell for a price war), buyer groups (cards
with `More buyers: +N%`; their story goes to the ledger, no list on screen).
